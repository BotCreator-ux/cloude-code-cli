# 🚀 Claude Code CLI Auto Installer

Installer otomatis untuk setup Claude Code CLI di Linux dengan cepat dan simple.

---

## ✨ Features

- ✅ Auto install Node.js
- ✅ Pilihan Node.js versi 21 - 26
- ✅ Auto install Claude Code CLI
- ✅ Auto setup API Key
- ✅ Auto create `settings.json`
- ✅ Support banyak distro Linux
- ✅ One click install

---

# ⚡ Quick Install

```
wget -O- https://raw.githubusercontent.com/BotCreator-ux/cloude-code-cli/refs/heads/main/install.sh | bash
```
atau:
```
curl -fsSL https://raw.githubusercontent.com/BotCreator-ux/cloude-code-cli/refs/heads/main/install.sh | bash
```
---

🔑 Cara Ambil API Key

1. Buka link invite berikut:

👉 https://freemodel.dev/invite/FRE-c0ca4c8e

2. Login / Register akun

3. Masuk ke menu API Keys

4. Klik Create key

5. Copy API key yang muncul

«⚠️ Jangan share API key ke orang lain.»

---

📦 Menjalankan Claude
```
claude
```
Cek versi:
```
claude --version
```
---

📁 Lokasi Config
```
~/.claude/settings.json
```
---

🔄 Update Claude Code
```
npm install -g @anthropic-ai/claude-code
```
---

❌ Uninstall
```
npm uninstall -g @anthropic-ai/claude-code
rm -rf ~/.claude
```
